# Data directories

Notebooks are expected to be launched from the repository root.

- `raw/`: local source data and downloads. This directory is ignored by Git.
  - `Yixing_data/`: source POI CSV files and population rasters.
  - `osm/`: files generated by `notebooks/01_download_osm.ipynb`.
  - `OpenStreetMap/`: optional Virginia Beach files used only by the archived SHAP notebook.
- `interim/`: generated `location_sites.csv` and `mapped_data.csv`. This directory is ignored by Git.
- `processed/`: small processed datasets required by the model notebooks and suitable for version control.

Required processed files:

- `h3_l7_df_new.csv`
- `h3_l7_df_yixing.csv`
- `h3_l7_df_yixing_full.csv`
- `pop_data.csv`

The population preparation notebook expects this local raster:

`data/raw/Yixing_data/chn_pop_2024_CN_100m_R2025A_v1.tif`
